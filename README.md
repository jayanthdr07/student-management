21# Student Performance Dashboard

A modern, responsive, and fully functional **Student Performance Dashboard** that helps students track their academic progress, attendance, and personal profile information. Built with **HTML, CSS, and JavaScript**, the dashboard is lightweight, mobile-friendly, and features a dark theme for better user experience.

---

## **Project Objectives**

- Provide students with a **centralized dashboard** to monitor their academic performance.  
- Track **subject-wise marks** and **attendance** efficiently.  
- Offer a **personalized profile section** for student details.  
- Enhance **user experience** with a clean, responsive, and intuitive interface.  
- Demonstrate **frontend development skills** suitable for web and Java/Spring Boot roles.

---

## **Features**

- **Dark Theme Only**: Optimized for low-light environments.  
- **Responsive Design**: Works on desktop, tablet, and mobile devices.  
- **Dashboard Overview**: Displays notifications, overall courses, assignments, attendance, and CGPA.  
- **Courses**: Lists all enrolled courses.  
- **Marks**: Shows **subject-wise internal, external, total marks, and grades**.  
- **Attendance**: Displays **subject-wise attendance** and overall percentage.  
- **Profile Section**: Student details including name, branch, and year.  
- **Logout**: Simulated logout functionality with alert confirmation.  
- **Interactive Sidebar Menu**: Navigate between pages seamlessly.  

---

## **Use Cases**

- **Students**: Quickly view academic performance, assignments, and attendance.  
- **Teachers**: Use the structure as a base to input marks and track student progress.  
- **Institutions**: Serve as a lightweight front-end prototype for internal dashboards.  
- **Portfolio Projects**: Showcase HTML, CSS, JS skills for frontend and full-stack roles.
